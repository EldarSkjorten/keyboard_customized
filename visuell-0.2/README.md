# Piano visuell 0.2 (reservekopi)

Uendret kopi av visuell 0.2, til bruk hvis noe i den nyeste versjonen (`visuell/`) ikke virker.

**Åpne:** https://eldarskjorten.github.io/keyboard_customized/visuell-0.2/

Bruker samme lager som `visuell/` (innstillinger, linjer og bilder), så det du har lagt inn, er med.
Merk: Safari og en Hjem-skjerm-app har hvert sitt lager. Åpner du denne i Safari, ser du det som er lagret i Safari.
